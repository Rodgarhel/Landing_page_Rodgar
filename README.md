Olivia Head Presentation

This project was created to showcase my HTML and CSS skills through the development of a personal portfolio website. The site is designed to highlight my work on the animated film *Olivia y el Terremoto Invisible*, featuring assets and content created by me. At the bottom of the page, you can also find links to the film's official social media channels for additional information and updates.


A responsive web design project focused on implementing CSS Media Queries to adapt layouts across different screen sizes and devices.
🔗 Live Demo

https://rodgarhel.github.io/Landing_page_Rodgar/
📌 Overview

This project demonstrates the use of Media Queries to create a responsive user experience. The layout automatically adjusts to different viewport sizes, ensuring usability on:

    📱 Mobile devices
    💻 Desktop screens

The goal is to practice responsive design principles and improve accessibility across multiple devices.
🚀 Features

    Responsive layout
    Mobile-first design approach
    Flexible content organization
    CSS Media Queries for different breakpoints
    Improved user experience on multiple screen sizes

🛠 Technologies Used

    HTML5
    CSS3
    Media Queries
    Responsive Design Techniques
